## 🔄 Updating Existing Threat Models

ThreatWeaver intelligently handles updates:

```bash
# First run - creates new file
python threat_weaver.py ./terraform --output THREATS.md

# After fixing issues - updates existing file
python threat_weaver.py ./terraform --output THREATS.md
```

**What happens during updates:**
- 🧹 Clears Checkov cache for fresh scan results
- 💾 Creates backup of existing files (if not generated by ThreatWeaver)
- 🔄 Regenerates threat model with current findings
- 📊 Shows updated risk counts and status

## 🛠️ Installation

1. **Install Checkov:**
   ```bash
   pip install checkov
   ```

2. **Download ThreatWeaver:**
   ```bash
   # Save the threat_weaver.py script to your project
   curl -O https://your-repo/threat_weaver.py
   ```

3. **Run on your Terraform:**
   ```bash
   python threat_weaver.py ./your-terraform-directory
   ```

## 🚀 Quick Start

### Prerequisites

```bash
pip install checkov
```

### Basic Usage

```bash
# Generate threat model for your Terraform directory

```

## 📋 Example Output

The tool generates a professional threat model document with:

- **Risk Assessment Framework** - Definitions and calculation matrix
- **Threat Analysis Table** - User-friendly threat descriptions with mitigations
- **Status Summary** - Overview of implemented vs. needed controls
- **Next Steps** - Prioritized action items

## 📚 Command Line Options

```bash
python threat_model_generator.py <terraform_path> [OPTIONS]

Required Arguments:
  terraform_path              Path to Terraform directory to scan

Optional Arguments:
  --output, -o               Output markdown file (default: THREAT_MODEL.md)
  --title                    Title for the threat model (default: AWS Infrastructure)
  --no-cache-clear          Skip clearing Checkov cache (faster but may use stale results)
```
